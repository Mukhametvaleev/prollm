# Changelog

The canonical changelog lives at
[CHANGELOG.md](https://github.com/Mukhametvaleev/prollm/blob/main/CHANGELOG.md) on GitHub. It is
maintained automatically by [release-please](https://github.com/googleapis/release-please) — every
Conventional Commit merged to `develop` is aggregated into the next Release PR.

Per-release notes are also published on the
[GitHub Releases](https://github.com/Mukhametvaleev/prollm/releases) page.
